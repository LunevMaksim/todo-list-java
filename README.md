## ✨ Функционал

## 🚀 Установка и запуск

### Требования
- JDK 17 или выше

### Консольная версия

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/LunevMaksim/todo-list-java.git
   cd todo-list-java
   ```

2. **Скомпилируйте:**
   ```bash
   javac *.java
   ```

3. **Запустите:**
   ```bash
   java ToDoApp
   ```

### Графическая версия (в разработке)
После реализации `SwingUserInput` появится отдельный класс `ToDoAppSwing` с оконным интерфейсом.

## 🏗 Архитектура проекта

Проект построен на принципе **отделения интерфейса от логики**:

- **UserInput** – интерфейс, описывающий все методы взаимодействия с пользователем (ввод строк, чисел, статусов, вывод сообщений).
- **ConsoleUserInput** – реализация для консоли (через `Scanner` и `System.out`).
- **TaskList** – не знает о консоли или Swing, работает только с `UserInput`. Это позволяет легко подменить консоль на графический интерфейс без единого изменения в бизнес-логике.
- **FileManager** – отвечает за файловое хранилище (CSV).

Такая архитектура делает код гибким, тестируемым и готовым к расширению.

## 🧪 Тестирование приложения

### Сценарии проверки консольной версии
1. **Добавление** – попробуйте разные статусы (полные и сокращённые).
2. **Редактирование** – измените каждое поле.
3. **Удаление** – удалите задачу, новая получит следующий ID.
4. **Сохранение** – закройте и откройте приложение, задачи должны остаться.
5. **Ошибки ввода** – введите буквы вместо цифр, неверный статус.

### Особенности
- Неверный статус → автоматически "Новая".
- Файл `tasks.csv` создаётся при первом запуске.
- `readInt` корректно очищает буфер, проблема с пустым вводом строк после числа устранена.
