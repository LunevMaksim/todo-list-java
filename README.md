## ✨ Функционал

### Графический интерфейс (Swing)
- ✅ **Показать все задачи** – отображает таблицу с ID, названием, описанием, статусом, датой и категорией
- ✅ **Добавить задачу** – диалог с полями (название, описание, статус, категория)
- ✅ **Редактировать задачу** – по кнопке или двойному клику на строке таблицы
- ✅ **Удалить задачу** – с подтверждением
- ✅ **Иконка приложения** – загружается из ресурсов
- ✅ **Кнопка выхода** – закрывает приложение

### Консольная версия
- Полный CRUD через меню (добавление, просмотр, редактирование, удаление)
- Интеллектуальный ввод статусов (принимает "нов", "в раб", "вып")
- Сохранение в CSV при каждом изменении

## 🛠 Технологии

- **Java 17** – язык
- **Swing** – графический интерфейс
- **Maven** – сборка и управление зависимостями
- **CSV** – хранение задач (разделитель `;`)
- **OOP, интерфейсы** – абстракция ввода/вывода (`UserInput`)

## 🚀 Установка и запуск

### Требования
- JDK 17 или выше
- Maven 3.8+ (или встроенный в IDEA)

### Сборка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/LunevMaksim/todo-list-java.git
   cd todo-list-java
   ```

2. **Соберите JAR с помощью Maven:**
   ```bash
   mvn clean package
   ```

3. **Запустите графическую версию:**
   ```bash
   java -jar target/todo-list-java-1.0-SNAPSHOT.jar
   ```

4. **Альтернатива – консольная версия:**
   ```bash
   java -cp target/classes com.todolist.ToDoApp
   ```

> При первом запуске будет создан пустой файл `tasks.csv` в корне проекта.  
> Иконка приложения автоматически загружается из `src/main/resources/images/icon.png`.

## 💡 Использование

### Графический интерфейс
- **Показать все задачи** – открывает таблицу с текущими задачами.
- **Добавить задачу** – заполните поля, нажмите OK. ID присваивается автоматически.
- **Редактировать задачу** – выделите строку, нажмите "Редактировать" или дважды кликните по строке.
- **Удалить задачу** – выделите строку, нажмите "Удалить", подтвердите.
- **Выйти** – закрывает приложение.

### Консольная версия
- Работает через меню в терминале. Все изменения сохраняются в тот же `tasks.csv`.

## 🔧 Сборка и зависимости

Проект использует Maven. Все зависимости (если появятся) добавляются в `pom.xml`.  
Для сборки исполняемого JAR используется `maven-jar-plugin` с указанием `Main-Class: com.todolist.UI.ToDoAppSwing`.

### Полезные команды Maven
- `mvn clean` – удалить папку `target`
- `mvn compile` – скомпилировать исходники
- `mvn package` – создать JAR
- `mvn exec:java -Dexec.mainClass="com.todolist.UI.ToDoAppSwing"` – запустить без сборки JAR
